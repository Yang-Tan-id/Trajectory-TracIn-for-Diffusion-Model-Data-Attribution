# Checkpoint/timestamp counterfactual experiments

These experiments reuse the existing 50k dataset, 192 LDS masks, 100 EMA
query trajectories, 50 base checkpoints, and observed LDS response arrays.
They do not retrain the LDS models.

## 1. Subset parameter unlearning

For every family and LDS mask, the update bank stores

```text
u_S = mean_{i in removed(S)} sum_c mean_t [-eta_c grad L_i(theta_c, t)]
theta_cf(S) = theta_final - scale * u_S
```

Thus the saved bank is an optimizer-update direction (`-eta * gradient`), and
subtracting it undoes the removed examples' estimated training contribution.
The default gradient checkpoints are raw and `theta_final` is EMA. The 192
counterfactual trajectories are evaluated together with batched functional
parameters, using each query's exact saved initial noise and prompt.

Run on four GPUs:

```bash
python -u 16_launch_checkpoint_counterfactual_4gpu.py \
  --experiment subset-unlearning
```

Logs:

```text
x3_lds_exp_50k/logs/cf_subset_updates_4gpu.log
x3_lds_exp_50k/logs/cf_subset_responses_4gpu.log
```

Final LDS summary:

```text
x3_lds_exp_50k/checkpoint_timestamp_counterfactual/
  subset_unlearning_responses/source_ema_scale_1/lds.json
```

## 2. Last-checkpoint predicted-noise delta direction

At checkpoint `c`, query snapshot `t`, and query `q`, define

```text
d_q,c,t = normalize(epsilon_last(x_q,t) - epsilon_c(x_q,t))
g_q,c,t = grad_theta_c <epsilon_c(x_q,t), d_q,c,t>
score_i  = sum_c mean_t eta_c <grad L_i(theta_c,t), g_q,c,t>
```

The direction is detached before differentiating. This is projection in the
predicted-noise output space; there is no CountSketch or parameter projection.
The current and last checkpoints use raw parameters, while the trajectory
states were generated by the final EMA model. The LDS evaluator reports both
the saved score and its negation so the sign convention is explicit.
The four-GPU launcher uses two timestamp shards per family and a train-gradient
batch size of 128; these are execution-only choices and do not alter the score.

Run on four GPUs:

```bash
python -u 16_launch_checkpoint_counterfactual_4gpu.py \
  --experiment delta-direction
```

Log and result:

```text
x3_lds_exp_50k/logs/cf_delta_direction_4gpu.log
x3_lds_exp_50k/lds/last_noise_delta_direction_raw_linear_both_signs.json
```

To run both experiments sequentially:

```bash
python -u 16_launch_checkpoint_counterfactual_4gpu.py --experiment all
```

All workers checkpoint after every assigned trajectory timestamp and resume
from existing partial files after interruption.
